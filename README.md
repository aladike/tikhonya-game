# Тихоня и Бубуль

Уютное 3D-приключение: крадись за лунными цветами, прячься от забавных монстров и строй дом для друзей. Без рекламы, аккаунтов и отправки игровых данных.

**Играть:** https://aladike.github.io/tikhonya-game/

## Разработка

Node.js 22. Установите Gitleaks (`brew install gitleaks` на macOS), затем `npm ci` и `npm run dev`. Адрес: http://127.0.0.1:5173/tikhonya-game/ . Проверки: `npm run lint`, `npm run typecheck`, `npm run build`. Предпросмотр сборки: `npm run preview`.

WASD / стрелки — ходьба, Shift — бег, C / Ctrl — тихий шаг, Space — прыжок, E — действие, Q — шишка. Перетаскивание справа вращает камеру. На сенсорном экране двигайтесь левым джойстиком и поворачивайте камеру правым пальцем.
