# Тихоня и Бубуль

Уютное 3D-приключение: помоги четырём смешным монстрам, собери команду животных и построй дом на Старом дереве. Днём — обустройство поляны, ночью — прятки, отвлечения и маленькие открытия. Без рекламы, аккаунтов и отправки игровых данных.

**Играть:** https://aladike.github.io/tikhonya-game/

## С чего начать

Найди светящийся цветок по указателю, подбери кнопкой ✋ и вернись к дому. Построй щенку домик через ⌂. На карте ⌖ выбирай новые тропинки; книга ▤ рассказывает о друзьях. Подарки превращают монстров в друзей и открывают помощников. Четыре дружбы ведут к Старому дереву.

- **Клавиатура:** WASD / стрелки — движение, Shift — бег, C / Ctrl — тихий шаг, Space — прыжок, E — действие, Q — шишка. 1 — собака приносит, 2 — отвлекает лаем, 3 — кошка разведает. Перетаскивание мыши — камера, двойной щелчок — захват указателя, Esc — пауза.
- **Сенсор:** левый палец двигает героиню, правый вращает камеру. Маленькое отклонение джойстика — тихий шаг, полное — бег. Справа крупные кнопки действий.

## Установка на iPad

Открой ссылку в Safari с интернетом, запусти игру, затем **Поделиться → На экран «Домой» → Добавить**. Открой значок «Тихоня». После первой полной загрузки игра доступна без интернета. В настройках появится сообщение, что офлайн-копия готова. Альбомная ориентация удобнее.

Прогресс остаётся только на устройстве. В **⚙ → Резервная копия → Сохранить файл** можно сохранить его в «Файлы»; «Загрузить файл» восстанавливает копию. Настоящее имя вводить не нужно. Safari может удалять данные сайтов: резервная копия полезна даже при установке на домашний экран.

Если игра предложит «Новая история готова · Обновить», нажатие сохранит прогресс и применит новый выпуск.

## Разработка

Node.js 22 и Gitleaks (`brew install gitleaks` на macOS). Затем:

```sh
npm ci
npm run dev
```

Локальный адрес: http://127.0.0.1:5173/tikhonya-game/ . `npm run build` собирает статическую игру и офлайн-кэш; `npm run preview` запускает сборку. Базовый путь берётся из `GITHUB_REPOSITORY` в CI.

```sh
npm run lint
npm run typecheck
npm test
npx playwright install chromium webkit firefox
npm run test:browser
npm run test:release
```

`test:release` сам запускает изолированный сервер сборки, устанавливает service worker и **выключает сервер**, чтобы проверить офлайн-перезапуск и сохранения. `GAME_TEST_URL=https://aladike.github.io/tikhonya-game/ npm run test:release` проверяет опубликованную версию; внешний сервер в этом режиме не отключается.

Строки: `src/strings.ts`, `src/locales/ru.json`; содержание историй: `src/content.ts`. Модули: `game` — движение/камера/шум, `adventure` — находки/помощники, `village` — строительство, `story` — дружба/зоны, `save` — локальные данные, `optimize` — объединение статичной геометрии. `npm run format` форматирует исходники.

План: GAME_PLAN.md. Решения и ограничения проверок: docs/DECISIONS.md. Этапы и результаты: docs/PROGRESS.md. Лицензии: LICENSE и CREDITS.md.
