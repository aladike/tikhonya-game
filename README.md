# Тихоня. Блочный остров

[Играть на GitHub Pages](https://aladike.github.io/tikhonya-game/)

Яркий остров из блоков. Строй замки, мосты и воздушные дорожки в творческом режиме. Мир сохраняется на устройстве; сервера, аналитики, рекламы и аккаунтов нет.

Работа идёт по **GAME_PLAN.md v2**. Этап 2 добавляет смену суток, ночное выживание, четыре вида смешных монстров, крафт, сундуки, печку и кровать. Старый творческий остров сохраняется. Чтобы попробовать ночь с монстрами: **«Мои миры» → пустой слот → «Выживание»**. Есть также мирное выживание и творческий режим. Три острова хранятся независимо, с именем, превью и датой.

Поворот камеры на смартфоне настраивается отдельно: **Настройки → «Поворот пальцем»**. В выживании Q / кнопка 🫧 выпускает пузыри (можно удерживать); нужна пузырь-палочка из книги рецептов. Действие использует еду, станции, фонарик и кровать. Первый закат — после семи минут игры. Полный цикл — двенадцать минут.

38 строительных блоков, инструменты трёх уровней, трофеи и рецепты. Две оригинальные многоголосые композиции: день ~137 с, ночь ~175 с, адаптивный слой преследования. При «Защекотали!» инструменты и хотбар остаются, остальные вещи ждут в постоянном светящемся пузыре. Следующий этап со всеми зверями начинается после второго плейтеста.

## Управление

- iPad: слева джойстик, справа поворот камеры. Короткий тап по грани ставит блок; удержание ломает. Кнопки справа — прыжок, полёт, тихий шаг/вниз и действие.
- Компьютер: WASD, Shift — бег, C/Ctrl — тише, Space — прыжок. ЛКМ удерживать — ломать, ПКМ — поставить, E — каталог блоков, 1–9/колесо — ячейка. F5 — вид, Esc — пауза и освобождение мыши.
- Двойной прыжок включает полёт. Во время полёта Space — вверх, C — вниз.

Настройки позволяют скачать/загрузить резервную копию острова. Старые сохранения стелс-версии несовместимы и не используются; они не удаляются из браузера.

## На iPad

Открыть ссылку в Safari → «Поделиться» → «На экран Домой». После первой полной загрузки игра кэшируется для офлайн-запуска. Системная установка и реальная производительность проверяются на устройстве во время плейтеста.

## Разработка

Node.js 22. `npm ci`, затем `npm run dev`. Адрес: `http://127.0.0.1:5173/tikhonya-game/`.

Проверки: `npm run lint`, `npm run typecheck`, `npm test`, `npm run test:browser`, `npm run build`, `npm run test:release`. Для браузерных тестов: `npx playwright install chromium webkit firefox`. В Linux CI WebGL проверяется через Xvfb. Отладка в игре: `?debug`.

Сборка публикуется официальным workflow Pages; base учитывает имя репозитория. PWA не обращается к сторонним серверам. Сканер секретов обязателен перед коммитами и в CI; локальный git email должен быть GitHub noreply.
