# Assets and software credits

## Original project assets

- Block atlas: `public/atlas.png`, generated by `scripts/generate-atlas.py` using the project palette; original 16×16 textures, MIT project license. No commercial-game textures.
- Block character, particles, clouds, butterflies and island landmarks: original procedural geometry in project source, MIT.
- Day score and music engine: original 64-bar composition, harmony, bass, melody, arpeggios, synthesis and percussion in `src/data/music.ts` and `src/engine/audio.ts`, MIT. No sampled or third-party music.
- Material and interface effects: original procedural synthesis, MIT.
- App icons: original project artwork, MIT. System fonts and platform emoji are rendered by the device; no font files or external services are loaded.
